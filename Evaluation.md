
      Model Evaluation
- Model evaluation is an iterative process that occurs alongside model building, assessing the model's quality and alignment with initial objectives.
- It consists of two main phases: diagnostic measures to ensure the model functions correctly and statistical significance testing to validate data handling.

Optimal Model Selection
- The evaluation process includes tuning parameters, such as the relative cost of misclassifying outcomes, to improve model performance.
- The optimal model is identified using the ROC curve, which helps visualize the trade-off between true-positive and false-positive rates for different misclassification costs.

ROC Curve
- The ROC curve is a diagnostic tool that quantifies the performance of binary classification models, aiding in the selection of the best model based on its ability to discriminate between outcomes.
- It plots the true-positive rate against the false-positive rate, providing insights into model effectiveness.
